# CamControl for Homebrew

Notarized builds of CamControl, a menu-bar companion for the Insta360 Link 2 and Link 2C.

```sh
brew install --cask trahloff/camcontrol/camcontrol   # install
brew upgrade --cask camcontrol                       # update
```

On first launch, allow camera access, local network access and the camera extension
(System Settings → General → Login Items & Extensions → Camera Extensions).
